# psy-511-scan-fdns-2026-spring
Files related to a course Rick Gilmore taught in Spring 2026.

## Contents

- `*.qmd`: [Quarto](https://quarto.org) format source files.
- `data/`: Supporting data files.
- `docs/`: Rendered website
- `exercises/`: Student exercises.
- `include`: Site-wide resources.
  - `bib/`: Bibtex and supporting files.
  - `css/`: CSS and SCSS style files.
  - `img/`: Image files.
  - `mov/`: Video files.
  - `snd/`: Audio files.
- `outlines/`: Topic outlines
- `renv/`: Files associated with the `renv` dependency management package.
- `resources/`: Old resource files.
- `slides/`: [Reveal.js](https://revealjs.com) formatted slides.
- `supplemental/`: Supplemental files.

## How to use

1. Clone the repository.
2. Install R package dependencies as recommended by prompts from `renv`.
3. Install [Quarto](https://quarto.org) if it's not already installed.
4. Execute `quarto render` from the command line.
